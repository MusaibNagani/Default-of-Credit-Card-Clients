
# Default of Credit Card Clients

## Overview
This project demonstrates various machine learning algorithms implemented in Python, including AdaBoost, Decision Tree, K-Nearest Neighbors, Logistic Regression, Random Forest, and Support Vector Machines. The project is designed to provide a practical understanding of these algorithms.

## Project Structure
```
- src/
    - ADABoost.py
    - DecisionTree.py
    - KNN.py
    - LogisticRegression.py
    - RandomForest.py
    - SVM.py
- docs/
    - ADABoost.pdf
    - DecisionTree.pdf
    - KNN.pdf
    - LogisticReg.pdf
    - RandomForest.pdf
    - SVM.pdf
    - CreditCardDefaulters.pdf
- data/
    - data.xls
- README.md
- requirements.txt
```

## Installation
To run the project, clone the repository and install the required dependencies:

```bash
git clone https://github.com/yourusername/Default-of-Credit-Card-Clients.git
cd Default-of-Credit-Card-Client
pip install -r requirements.txt
```

## Usage
Each script in the `src/` folder corresponds to a different machine learning algorithm. You can run any script independently. For example:

```bash
python src/ADABoost.py
```

Ensure that the `data.xls` file is present in the `data/` directory, as the scripts depend on this dataset.

## Documentation
The `docs/` folder contains detailed explanations and results for each algorithm used in the project. Refer to these documents for a deeper understanding of the methods and their performance.
